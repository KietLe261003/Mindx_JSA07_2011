# THE TIMELESS GARDEN — Khu Vườn Của Những Điều Tri Ân (20/11)

Website nghệ thuật tương tác chào mừng Ngày Nhà giáo Việt Nam 20/11.

## Hướng dẫn chạy bằng VS Code Live Server
1. Giải nén tệp `the-timeless-garden.zip`.
2. Mở thư mục `the-timeless-garden` bằng **Visual Studio Code**.
3. Cài đặt tiện ích mở rộng **Live Server** (nếu chưa có).
4. Nhấp chuột phải vào tệp `index.html` và chọn **Open with Live Server** (hoặc nhấn nút **Go Live** ở thanh trạng thái góc dưới bên phải).
5. Bật nút **Âm thanh: Bật** ở góc trên bên phải màn hình để thưởng thức giai điệu Piano hòa cùng các hiệu ứng tương tác.
